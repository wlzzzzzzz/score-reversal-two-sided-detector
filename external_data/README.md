# Optional generation inputs

Place original source corpora and historical intermediate generation inputs
here when rerunning the corresponding preparation scripts. These resources
must be obtained from their original providers under their terms.

The final 80-cell benchmark is included under `data/benchmark/`; the main
rerun in `docs/REPRODUCE.md` starts from those texts and does not need these
additional inputs. Models and optional upstream code use the separate
`models/` and `external_code/` directories.
